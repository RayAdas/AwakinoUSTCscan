# 数据集格式约定

## OSCget原始数据
- data/OSCget/{$BeginTime}/
  - 若干.npy文件，不保证一定是signalLength长
  - index.ini
    - [Grid]
        - minX(mm)
        - minY(mm)
        - maxX(mm)
        - maxY(mm)
        - numX
        - numY
    - [Wave]
        - sampleRate(Hz)
        - head2trigger(s)
        - signalLength

## 回波序列数据

- data/EchoSeq/{$BeginTime}.npz
  - waveform_data: np.ndarray in shape(numY\*numX\*signal_length)
  - grid_info：包含6个int value的字典
  - wave_info：包含3个float value的字典
  - is_actual_measurement：bool值，指示是否为实测数据
  - simulation_paras(optional)：NotRequired[np.ndarray[list[EchoInfo]]]，该键仅在is_actual_measurement为False时存在，shape(numY\*numX)

## NetTOF数据集

- trigger_trim_time(s)：忽略波形头部长度。注意，这里指的是从trigger开始忽略的长度，而不是从head开始。
- direct_component：np.ndarray in shape(numY\*numX)
- input：np.ndarray in shappe (numY\*numX\*INPUT_SIZE\*2)，波形和包络数据，此处的数据已经过头部裁切和去直流分量。
- tgt：np.

### 常数(Must Be)
- 序列长度：INPUT_SIZE=5000
- 采样率：SAMPLERATE=500e6
